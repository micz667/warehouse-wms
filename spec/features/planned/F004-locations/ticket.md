# F004 · Locations can be scanned

## Outcome

Admin can define locations with codes; hall users can pick or scan a location when moving stock.

## Scope

- Location model with code + label; list/create/edit.
- Flat list is enough; hierarchy optional if cheap.

## Out of scope

- Multi-warehouse, putaway rules.

## Acceptance

- Location codes are unique.
- Location appears as a selectable/scannable target in a stub picker used by later movement flows.
