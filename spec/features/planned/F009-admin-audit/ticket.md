# F009 · Admin sees users and movement history

## Outcome

Admin manages users/roles and can filter movement history by date, item, location, actor.

## Scope

- User CRUD or invite+role change; movement list with filters.

## Out of scope

- Full SIEM, immutable legal archive.

## Acceptance

- Admin can change a user role.
- Movement history shows the F005/F007 posts with filters that narrow results.
