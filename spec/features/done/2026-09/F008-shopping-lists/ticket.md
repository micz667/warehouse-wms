# F008 · Architects build shopping lists

## Outcome

An architect builds a draft list from the catalog, submits it for fulfillment; warehouse can check off lines.

## Scope

- List + lines (item, qty, note); statuses draft → submitted → done (minimal).
- Warehouse checklist UI.

## Out of scope

- Purchasing, supplier orders, Symfonia PO.

## Acceptance

- Architect creates and submits a list.
- Magazynier sees submitted lists and can mark lines checked.
- Admin/architect can view list history.
